# Port Radar — Web

Next.js landing for [Port Radar](../mac). Lives directly in `apps/web` (no nested app folder).

## Dev

```bash
cd apps/web
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
npm run dev      # local dev server
npm run build    # production build
npm run start    # serve production build
npm run lint
```
